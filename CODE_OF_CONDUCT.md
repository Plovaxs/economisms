# Code of Conduct

## Our standard

This project is small, technical, and evidence-driven (see
[README.md § The evidence discipline](./README.md#the-evidence-discipline)).
The same standard applies to how people treat each other here as to how
claims are made about the code: be direct, be accurate, and say plainly
when you don't know something or when a change falls short, rather than
papering over it.

Participants are expected to:

- engage in good faith — disagree with a claim or a design choice, not with
  a person;
- back technical criticism with something checkable (a failing test, a
  reproduction, a citation to a specific line), the same bar this project
  holds its own commits to;
- accept correction gracefully, and give it the same way;
- respect that this is presently a single-maintainer research repository —
  response times and priorities are limited accordingly.

Unacceptable behavior includes harassment, personal attacks, discriminatory
language or jokes, publishing others' private information without consent,
and sustained disruption of issues/discussions/reviews.

## Scope

This applies within all project spaces — the repository's issues, pull
requests, discussions, and any other official communication channel — and
when someone is representing the project elsewhere.

## Enforcement

Report a concern the same way you would report a security issue when you'd
rather it not be public: via this repository's **Security** tab → **Report
a vulnerability**, which reaches the maintainer privately (see
[SECURITY.md](./SECURITY.md)) — or, for non-sensitive conduct concerns, by
opening a regular issue. Reports will be handled as confidentially as the
reporter requests allow. Maintainers may remove, edit, or reject comments,
commits, issues, and other contributions not aligned with this Code of
Conduct, and may temporarily or permanently restrict anyone whose behavior
is harassing, threatening, or otherwise unacceptable.

This document is adapted in spirit from the
[Contributor Covenant](https://www.contributor-covenant.org/), simplified
for a single-maintainer research project rather than copied verbatim as a
template neither read nor meant.
